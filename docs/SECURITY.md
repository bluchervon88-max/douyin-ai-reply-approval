# 安全与隐私

## 这个项目能做什么

它会用你的抖音登录态读私信、生成回复、按你的审批发送。它也能在白名单里自动发送。

**它不是沙箱。** 一旦自动范围配置过宽，它可能把你的话发给不该发的人。第一次使用请保持自动关闭，先人工审批。

## 密钥

需要保管的密钥：

- `FEISHU_APP_SECRET`
- `DEEPSEEK_API_KEY`
- 抖音登录态（`.profile/` 里的 cookie）

规则：

- 只放在 `.env` 或系统环境变量，不要写进代码、不要提交。
- 不要把 `.env`、`state.json`、`watcher.log`、`people/`、`.profile/` 发给别人。
- 如果 `FEISHU_APP_SECRET` 曾经出现在公开仓库/截图/聊天里，去飞书后台重置。
- 如果 `DEEPSEEK_API_KEY` 泄漏，去 DeepSeek 控制台吊销并重建。

## 本地 API

`watcher10.mjs` 的 `/api` 只绑定 `127.0.0.1`，返回运行状态（会话数、pending、统计）。不要把它反代到公网；它没有鉴权。

## 数据文件

| 文件 | 内容 | 是否进仓库 |
| --- | --- | --- |
| `state.json` | 会话游标、待审草稿、白名单、统计 | 否 |
| `watcher.log` | 运行日志，含聊天摘要 | 否 |
| `people/` | 人物档案 | 否 |
| `backups/` | state 备份 | 否 |
| `.profile/` | 抖音 cookie | 否 |
| `*.png` / `*.bin` / `*.jsonl` | 抓取产物 | 否 |
| `.env` | 密钥 | 否 |

`.gitignore` 已覆盖这些路径。提交前仍然建议跑：

~~~bash
git status --short
git diff --cached
~~~

## 自动发送的风险

- 发错人：白名单/自动范围配置错误，或会话改名。
- 发错内容：模型生成不合适的话；敏感词闸门只能挡一部分。
- 重复发送：网络抖动、页面状态误判；代码有防重和发送前检查，但不能保证 100%。
- 平台风控：自动化操作可能触发验证/限流/封号。

建议：

1. 自动只开给少数熟人。
2. 设每日上限和静默时段。
3. 定期看 `watcher.log` 和飞书卡片。
4. 出问题先 `自动 关`，再排查。

## 模型数据

`draft2.mjs` 会把最近聊天上下文、人设、语料节选发给 DeepSeek API。不要在没有告知对方的情况下把敏感对话交给第三方模型；遵守你所在地区和平台的规定。

## 披露

如果你基于这个项目做公开部署，请保留本安全说明，并在自己的 README 里说明数据流向。
